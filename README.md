# Sentinel Lab

Учебный проект для практического изучения работы SOC-инженера.

## Goal

Получить практический опыт работы с логами, обнаружением атак, анализом событий информационной безопасности и реагированием на инциденты.

## Components

- Web application — небольшое веб-приложение для создания событий и тестирования защиты.
- Honeypot — приманка для наблюдения за сетевой активностью.
- Process monitor — мониторинг процессов на сервере.
- Collector — сбор и обработка логов.
- Detection engine — поиск подозрительной активности по правилам.
- API — интерфейс для просмотра событий и алертов.
- Automation — автоматизация реагирования и обслуживания.

## Status

Project in development.

## Ethics

Все атаки и тестирование проводятся только на собственной инфраструктуре.
